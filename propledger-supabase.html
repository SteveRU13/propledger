One-time setup (~5 min):
1. Go to supabase.com → New project (free)
2. Project Settings → API → copy Project URL and anon public key
3. Go to SQL Editor → run the setup SQL below (it creates both the expenses and income tables)
4. Go to Storage → create a bucket called receipts (public)
5. Paste URL, key and choose an access code above
